### A11Y-001 · Keyboard-only use (web) `P1`

- [ ] **Actor:** Tester (device / platform / build check) (`TST`) · **Screen:** `(all)`
- **Preconditions:** Desktop Chrome
- **Steps:**
  1. Tab through login, sidebar, a list, a drawer form, a dialog
  2. Press Escape in a drawer/dialog
- **Expected:** Visible focus ring on every control; logical order; Escape closes the top overlay; focus returns to the opener.
- **Must be refused / negative:** No keyboard trap; no unreachable control.
